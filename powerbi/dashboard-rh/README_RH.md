# 📊 Dashboard de Recursos Humanos

## 🎯 Sobre o Projeto
Dashboard interativo desenvolvido no Power BI para análise de métricas de RH, permitindo visualização de indicadores de funcionários, salários e frequência.

## 📈 Principais Análises

### 👥 Perfil dos Funcionários
- **Funcionários por Gênero** - Distribuição de colaboradores
- **Média de Idade por Gênero** - Perfil etário dos times
- 🔍 *Campo de busca disponível para filtrar funcionários*

### 💰 Análise Salarial
- **Salários por Filial** - Comparativo entre unidades
- **Salários por Departamento** - Média salarial por área
- **Salário por Funcionário** - Detalhamento individual

### 📅 Controle de Frequência
- **Quantidade de Faltas por Filial** - Monitoramento de absenteísmo

## 🛠️ Funcionalidades
- ✅ Filtros interativos
- ✅ Campos de busca para localizar funcionários específicos

## 📂 Arquivos
- `Dashboard RH.pbix` - Arquivo fonte do Power BI

## 🚀 Como Utilizar
1. Baixe o arquivo `.pbix`
2. Abra no Power BI Desktop
3. Explore as análises e filtros disponíveis
